# PirePoint Data Layer

The data layer separates verified evidence from interpretation.

## Rules
- Every material fact must have one or more source IDs.
- Primary sources are preferred for company-specific facts.
- Store the observation date/as-of date separately from retrieval time.
- Never silently overwrite historical observations.
- Classify content as fact, calculation, interpretation, forecast, opinion, or unknown.
- If evidence conflicts, preserve both observations and flag the conflict.
- Public pages must not claim live data until the underlying value has been verified.

## Source tiers
1. Primary official source
2. Institutional/regulatory source
3. Established financial data/news source
4. Commentary
5. Social/user-generated content

Social sources may generate research leads but do not establish material facts by themselves.
