# Authoritative Indian market sources

Initial source hierarchy for PirePoint:

1. SEBI corporate-filings directory — use it as the map to listed-company filing categories.
2. NSE corporate filings — announcements, financial results, shareholding patterns, board meetings, corporate actions and related filings.
3. BSE corporate filings — announcements, results, corporate actions and board meetings.
4. Company investor-relations pages — use for company-originated reports, presentations and disclosures.

SEBI's corporate-filings directory explicitly links the relevant NSE and BSE filing categories. NSE also exposes corporate filings including financial results and shareholding patterns. These sources are evidence inputs; the exchange itself notes that uploaded company information is the company's responsibility and is not independently verified by the exchange.

Source URLs are maintained in the source registry rather than embedded throughout application code.
