# PirePoint automation contract

## Automated now
- GitHub Pages deployment
- structural validation
- authoritative NSE universe refresh
- point-in-time generated universe snapshots
- research queue maintenance foundation
- compliance/release-gate checks
- material-change detection foundation

## Automated next
- NSE/BSE filing collection with caching and rate limits
- company IR source discovery
- structured financial extraction
- source conflict detection
- research drafting and red-team passes
- public "What Changed" publication
- search-demand ingestion

## Human approval remains mandatory
- regulatory classification questions
- personalised/advisory functionality
- material external commercial commitments
- security incidents
- publication where the compliance gate cannot establish safe public-information status

Automation must stop rather than guess when evidence is missing or a source changes unexpectedly.
