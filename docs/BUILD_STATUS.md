# PirePoint build status

## Implemented
- Static public website foundation
- GitHub Pages deployment workflow and custom-domain file
- Evidence/source schema
- Source registry
- Point-in-time company records
- NSE ingestion foundation (dry-run)
- Material change detection
- Red-team protocol
- Compliance publication gate
- What Changed public surface
- Reusable company intelligence page
- Company-page schema
- Initial company master/universe design
- Monitoring policy
- Automated CI validation

## Not yet autonomous
These require external access, credentials, contractual/licensing review, or human approval:
- Production exchange/API ingestion
- Licensed market-data feeds
- DNS changes at the domain registrar
- Final legal/regulatory review
- Payment processor and subscription setup
- Production email/SMS/push credentials
- Large-scale search-demand provider access
- Personalised/advisory functionality

## Operating principle
No credential is committed to GitHub. No unverified market number is presented as live. No regulated/personalised recommendation is silently generated.
