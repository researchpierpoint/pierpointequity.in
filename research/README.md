# PirePoint Research Pipeline

Pipeline:

search signal -> research task -> source collection -> extraction -> validation -> calculations -> analyst draft -> red team -> compliance gate -> publication -> monitoring

Each research item should record:
- research ID
- created/updated timestamps
- subject
- question
- evidence
- calculations
- interpretation
- uncertainty
- bull/base/bear scenarios
- thesis breakers
- next verification date
- model/version metadata
- publication status

No recommendation language or personalised advice should be generated by the public information layer.
