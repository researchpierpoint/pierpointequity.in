# PirePoint Compliance Firewall

Before public publication, classify the output and stop uncertain/high-risk items.

Checks:
- Is the statement factual and sourced?
- Is the source current enough for the claim?
- Is the content personalised?
- Does it become a buy/sell/hold recommendation or price target?
- Does it imply guaranteed or certain returns?
- Are conflicts disclosed?
- Does the feature potentially constitute regulated activity?

If uncertain: STOP and route to human review.

The firewall is a product control, not a substitute for professional legal/regulatory advice.
